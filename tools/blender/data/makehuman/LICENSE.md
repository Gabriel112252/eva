# Dados do MakeHuman (CC0 1.0)

Arquivos desta pasta são **dados** (malha base `hm08`, targets de morfologia, definição e pesos do rig
compatível com Mixamo, metadados de grupos de vértices, máscaras de textura e olhos) do projeto MakeHuman,
copiados dos repositórios públicos:

- https://github.com/makehumancommunity/mpfb2 (`src/mpfb/data`)
- https://github.com/makehumancommunity/makehuman (`makehuman/data/eyes`)

A equipe do MakeHuman liberou esses assets sob **CC0 1.0 Universal** (ver `LICENSE.ASSETS.md` e a seção
"Concerning the output" do `LICENSE.md` do mpfb2): não há restrição de uso, inclusive comercial, nem obrigação
de atribuição. Nenhum código (GPL) do MakeHuman/MPFB é executado ou distribuído neste repositório — o gerador
`tools/blender/make_character.py` é código próprio do projeto EVA que apenas lê estes arquivos.
